# Calton View Café — Website

Single-page website concept for **Calton View Café**, 9 Jeffrey Street, Edinburgh EH1 1DR (just off the Royal Mile).

## View it
Open `index.html` in any browser — no build step. To host it, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## What's inside
- Hero, story, guest favourites, tabbed menu (real 2026 prices), gallery, community events, reviews, visit info with map
- Fully responsive, no dependencies beyond Google Fonts

## Before going live
- Replace hotlinked photos with the café's own images (`IMG` object at the bottom of `index.html`)
- Replace the placeholder logo badge with the real logo
- Confirm phone number and opening hours with the owner
